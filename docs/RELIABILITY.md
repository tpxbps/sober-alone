# 状态与工作流恢复约定

## 角色状态

线索工具与发言反应使用同一套数组输出和保存服务。每条更新表示指定角色的最新绝对判断，允许分数下降或归零，覆盖理由与回应标记；未提交的角色保持原值。完整输出校验成功后才写入，数据库统一使用角色 ID，调度分数由同一状态派生。

反应输入包含当前角色的个人剧本全文、自己的已有心理状态、公开线索和本次发言。不会读取其他角色的私有心理状态。真人反应 schema 不要求摘要，应用直接保存原话；AI 反应失败时保存该条原文。

待消费发言按记录 ID 去重，各 AI 独立消费。仅在有效发言成功提交时清除实际注入的条目，生成失败不会清除。发言、次数和待处理反应一起提交，反应完成后才选择下一位。未完成反应可在恢复对局时继续，已完成角色不会重复应用。

## 数据迁移与检索

迁移 `0009` 添加待处理发言状态，并将旧姓名键转换为角色 ID。优先使用对局快照中的姓名；姓名项与 ID 项冲突时保留 ID 项并重建调度分数。旧存档没有状态更新时间，迁移不尝试推断历史先后。

升级前应备份数据库，在副本上执行 `alembic upgrade head` 并检查 SQLite 完整性。降级删除新字段不会还原已规范化的旧状态；需要原始状态时恢复迁移前备份。

RAG 仅对当前角色、个人剧本内容摘要值和完整索引批次启用。旧索引、空索引和不完整索引使用全文；检索异常或索引失效时返回本局角色的个人剧本快照。升级不会自动重新向量化历史内容。

## 创作与审查

必需转换任务最多调用三次，保留成功任务并仅重试失败任务。输入内容变化或明确重新生成会使缓存失效。必需任务失败不生成可游玩剧本，不以全知大纲或占位内容代替结果；界面显示“抱歉！系统发生未知错误，请稍后重试。”并提供重试。

数据先规范化，再校验、检查和保存。显式空字符串不回退到旧字段。保存入口再次检查结构及当前内容对应的质量、安全结果。

安全审查覆盖规范数据中的完整展示文本和模型上下文。文本按字段、段落分块，每块至多 6000 字符，长字段相邻块重叠 300 字符，并发至多两块。短内容同样送审。内容拒绝返回具体原因；技术失败最多尝试三次。只有所有分块明确通过，且内容指纹和规则版本仍一致，才能保存。质量风险确认不能替代安全通过。

回归测试覆盖角色状态、待消费发言、恢复调度、索引版本、转换重试、保存门槛、安全分块和数据库副本迁移。真实模型验收与使用替身的离线回归应分别记录。
