# 大厅与全局主题

首屏按难度展示全部剧本，保留接口顺序。选本后在原页上方呈现完整封面、故事资料和角色配置。桌面双栏等高，角色列表内部滚动；平板和手机顺序展开。标题位于封面下方，卡片不重复显示分组难度。

## 选本与入局

Homepage 通过短暂淡出、位置切换和淡入衔接列表与详情。返回恢复原卡片位置；鼠标操作不保留卡片焦点，键盘操作恢复焦点。ScriptSetup 呈现详情，useScriptSetup 管理请求取消、自动分配、手动配置保留和创建重试。详情复用卡片评分细则。

开始后立即遮罩并创建会话。光晕先扩散，再以 3.8 秒周期持续呼吸；状态和历史都成功才进入游戏。初始化失败沿用已创建会话重试，重复点击不重复创建。减少动态效果或静止偏好下禁用动画。

模型名称在显示适配器统一旧版 deepSeek-v4 大小写，不改变模型 ID 或请求。菜单只展示慢响应、超时和不可用等异常提示。

## 流光

LobbyAtmosphere 动态加载 fluidAtmosphere，使用 Three.js 0.186.0 与 three-fluid-fx 0.1.0。一套渲染器和流体场服务背景与可见封面，文字和控件保持 DOM。光源直接使用最新指针坐标，下一帧响应。流体只影响形态与短暂余波，已移除密度等高线纹路。

自发流光间隔约 3.2–5.2 秒，约三分之一带宽幅波动。卡片约 250 ms 显现、800 ms 回暗，核心信息始终可读。滚动、尺寸和场景过渡同步封面位置与透明度；后台暂停。触屏、静止模式、减少动态效果及 WebGL 故障保留清晰静态内容。

## 主题与素材

frontend/src/index.css 统一深蓝灰、米白、浅金与银蓝变量。品牌和故事标题使用 Noto Serif SC，正文与操作使用无衬线。成功、警告和错误保留语义区别。游戏人物等宽等高，长姓名职业省略，悬浮展示完整内容。

frontend/public/lobby/ 中 theatre.webp、game.webp、workshop.webp 分别用于大厅、游戏与创作；后两张为 2048×1152 WebP。dragon.png 为 256×256 RGBA 浅金龙形图标，真实透明通道。背景与龙形素材通过内置 imagegen 制作；图标从生成的黑白轮廓导出透明 PNG。字体许可见 NotoSerifSC-OFL.txt。

## 验证

在 frontend 运行 pnpm lint、pnpm test、pnpm build、pnpm test:e2e。大厅回归覆盖创建与初始化失败、慢请求、模型健康延迟、快速换本、评分、键盘、触屏、320–1440 px 布局及 WebGL 回退。
