## 作者看到的变化

- 大纲维护当前有效设定。同一条输入可以回答选项并更正前文，按段修订相关关系、动机和线索，保留未受影响段落；变更说明、撤销和旧版本可查。持续输入框允许在生成过程中提交修订，取消未完成请求后从最近完整版本继续。
- “停止提问”直接依据现有设定整理，不再将 AI 推荐选项自动视为作者确认。最终人工编辑稿作为下游依据。
- 未点独立保存也能直接继续；等待页显示此次提交快照，生成失败和刷新后仍可恢复草稿。请求编号去重，过期 checkpoint 拒绝覆盖新版。
- “输入改进方向 · 重新生成”要求填写反馈，并使用当前编辑稿；每节点最多三次成功重写，次数不显示。技术失败和资源失败另行重试。
- 游戏数据改为公开介绍、角色、分轮线索、主持流程、真相与结局五个工作区。桌面侧栏、手机章节选择、受众标签、字段说明、长文预览与放大编辑；角色使用稳定 ID，提交时统一适配旧格式。
- 质量检查为可选、每工作流一次。重复打开读取原报告；编辑后标明报告对应旧版本；点击问题定位到对应角色或线索。报告有问题、检查失败、未检查均不阻止继续。合规评估和结构校验保留。
- 资源阶段显示完整任务清单、实时状态与单项失败重试。SSE 断开后重连，轮询补齐，服务器重启从持久化进度恢复，已完成且输入未变的任务不重复执行。
- 完成页增加感谢语；创意框轮播三段故事引导，每字约 45 毫秒、段末停留 8 秒，聚焦/输入时停止，减少动态效果模式显示静态示例。

## 状态和信息边界

`outline_session.canon` 只保存有效作者要求；修订记录保留用户原话和完整撤销快照。后续生成不重新混合已废弃决策。共创选项在作者选择前不能进入有效设定。

拆分从最新确认终稿提取 `DisclosurePlan`，包含角色、开局时点、逐字原文依据、知情角色及公开轮次。程序检查人数、角色引用、来源范围、本人行为和未来事实的知情范围。个人本仅接收开局公开及本人已知材料，公开简介仅接收公开材料；速览和 AI 资料从同一份个人本派生，完整真相独立生成。拆分不再使用初稿正则角色名单，也不让旧大纲约束覆盖已确认终稿。

针对真实验收发现的“他不知道杯中有毒”泄密，程序拒绝将这类不知情陈述分配为角色已知事实。混合知情范围的原文允许引用更小的连续片段；格式/来源修复有上限，不能退回全知稿生成个人本。角色速览设置长度上限，避免复述整篇个人本。

审稿明确初稿、终稿为作者可读的全知稿，不能要求作者提前完成个人本拆分、字段或资源；区分开局未知与后续轮次公布，检查同义表述后才能报告信息缺失。

复用已有 checkpoint 与操作表，无新增迁移。进度包含操作 ID、递增序号和实际阶段；保存错误可恢复，单项资源重试也使用持久化操作。生成审计记录提示词版本、配置模型、供应商返回的模型标识/用量（如有）、输入 checkpoint/内容指纹、反馈、输出指纹。供应商没有返回标识时不伪造。

旧大纲与旧质检节点保留恢复路径。回溯历史时保留工作流级的质检记录和重写计数。质检报告不再参与路由和数据库保存的强制拦截，旧报告在内容变更后标记过期。

## 复现

常规检查在对应目录运行：

```sh
# backend
python -m pytest -q
python -m ruff check .
# frontend
pnpm test
pnpm lint
pnpm build
pnpm exec playwright test e2e/workshop-ux.spec.ts e2e/outline-cocreation.spec.ts e2e/script-editor-recovery.spec.ts e2e/script-quality.spec.ts e2e/endings-editor.spec.ts --project=flows --workers=1
```

Windows 本机默认临时目录权限受限时，可为 pytest 指定工作区内新的 `--basetemp`。如单独启动了预览服务，可以设置 `PLAYWRIGHT_REUSE_SERVER=1` 与对应 `PLAYWRIGHT_PORT` 复用它。

真实供应商验收脚本是显式启用项，不加入日常 CI，会产生模型与资源调用费用。从 backend 目录运行：

```sh
python scripts/verify_workshop_live.py --env-file /path/to/local.env --output-dir ../output/workshop-text
python scripts/verify_workshop_live.py --env-file /path/to/local.env --output-dir ../output/workshop-assets --resources
```

输出目录需要放在 Git 忽略的本地位置；其中包含测试所有者凭证和生成内容，不能提交。脚本只在隔离目录中建库；纯文本模式禁用图片/语音/向量服务配置，资源模式使用实际已配置供应商。发生中断可用同一目录恢复；`--retry-failed` 仅重试已保存的失败阶段。
