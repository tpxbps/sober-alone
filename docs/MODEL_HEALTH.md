# 模型测速

进入大厅即启动测速，结果逐个展示；前端每 2 秒获取进度，同一批请求合并。完成结果缓存 30 分钟，支持手动重测，测速不阻止选角或开始游戏。

用户提示使用“响应较慢”“测速超时，请稍后重试”“测速失败，请重试”，不展示内部任务分类。内部仍保留延迟与失败维度，便于诊断。

测速与真实游戏共用模型参数、角色 Agent 构建、结构化输出和解析。轻量发言测首字（15 秒预算），轻量反应测有效分析（30 秒预算）；真实游戏保留较宽等待和重试。短样本不能代表整局延迟或推理质量。

GLM-5.3-Flash 使用实测兼容的 low 推理强度与 JSON 模式。共享提示明确字段类型、0–1 绝对怀疑程度；纯字符串要点数组无损合并成文本，其他错误仍进行结构校验。

手动诊断脚本在 backend/scripts/model_health_diagnostic.py 和 model_game_audit.py。它们会调用已配置模型并产生费用，不在常规测试中执行；游戏审计使用独立数据库和自带虚构样例。输出请放入忽略目录 .local-data，勿提交凭据或运行数据。
