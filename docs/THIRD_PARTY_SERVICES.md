# 第三方服务、数据流与费用

| 服务 | 用途 | 可能发送的数据 | 是否必需 | 费用责任 |
|---|---|---|---|---|
| DeepSeek | 主对话、结构化输出、工具调用、剧本创作 | 角色设定、个人剧本、公开线索、玩家发言、创作内容 | 主流程必需 | Key 持有人 |
| StepFun | 摘要、流式 TTS | 对话历史或待合成文本 | 可选 | Key 持有人 |
| 智谱 | Embedding / RAG | 角色个人剧本文本和检索查询 | 可选 | Key 持有人 |
| 火山方舟 / 豆包 | 图片与可选角色模型 | 剧本摘要、人物外观提示词 | 可选 | Key 持有人 |
| MiMo | 静态 TTS | 系统消息、角色个人剧本 | 可选 | Key 持有人 |
| 千问 | 可选角色模型 | 角色设定、个人剧本、线索和玩家发言 | 可选 | Key 持有人 |

能力端点只返回配置状态和禁用原因，不返回 Key。Key 只从本地环境变量或被忽略的 `backend/.env` 加载。

0.1.0 候选已对 DeepSeek 的普通/结构化/工具/游戏流式链路，以及 StepFun 的摘要/TTS 做最小 live 冒烟。智谱、豆包、MiMo 与千问没有在本次候选中做 live 验证；普通 CI 不配置任何供应商 Key，也禁止测试访问外部主机。

本项目无法替你保证供应商的价格、可用区域、数据保留、训练使用、内容政策或服务连续性；这些信息可能变化，请在启用前查阅对应供应商的最新官方条款。不要提交无权处理的个人信息、第三方秘密或未授权内容。
